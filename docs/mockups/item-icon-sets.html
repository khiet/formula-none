Instrument panel / item slot

Item icon sets, five directions

Each sheet draws the three items the protocol knows (boost, hazard, homing) plus the item box, then mounts them in a copy of the slot as it ships today: a 6.2 em gold bevel on the 16-bit panel. Every icon is inline SVG, so the winner drops straight into the web app.

1. Sixteen Bit

matches the current panel

Sixteen by sixteen sprites in the panel's own palette, outlined in the panel's outline brown. Reads at any HUD scale because the browser scales the pixels, never the strokes.

Boostflame, 16x16
Hazardspiked mine, 16x16
Homing projectilemissile, 16x16
Item boxcube, 16x16

Mounted in the slot. The brown outline is the slot's border colour, so the sprite reads as part of the frame.

2. Sticker Pack

flat vector, thick outline

Kenney-adjacent flat shapes: one fill, one shade, one highlight, a heavy rounded outline and a sticker edge. The look of the kart model itself.

Boostflame + chevrons
Hazardspiked mine
Homing projectilemissile + lock ring
Item boxcube with a ?

Mounted in the slot. Gold on gold needs the brown outline to separate the box from its frame; it holds.

3. Pit Wall Blueprint

monoline technical drawing

Single-weight line work on drafting blue, with the item's real tuning value as the dimension callout: the engineer's view of a toy. Icons double as a tooltip the player can learn from.

Boostcallout: 1.5 s, +40%
Hazardcallout: 1 m behind, 30 s
Homing projectilecallout: 1.6x top speed
Item boxcallout: 8 per track, 3 s

Mounted in the slot. This set asks the slot to go blue when it holds an item; on the gold frame the lines vanish. Callouts drop at HUD size and keep the line work.

4. Roadside Pests

the funny one

Each item is a creature that would plausibly be on the track anyway, with a face that tells you its mood. A snail with a rocket strapped on, a cone that hates you, a seagull that has picked its target, and a lunchbox something is living in.

Boostsnail, rocket, regret
Hazardcone, arms crossed
Homing projectileseagull, locked on
Item boxlunchbox, occupied

Mounted in the slot. The faces survive at 68 px; the seagull's reticle is the first thing to go if the HUD unit shrinks.

5. Tyre Marks

the surprise

No object at all. Each icon is the mark the item leaves on the asphalt, seen from above: the rubber a boost lays down, the loop a spin-out scrubs, the arc a projectile carves to its target, and the dashed outline where a box sat. The player learns the icons by seeing them on the track.

Boosttwo streaks, laid down
Hazardthe spin-out loop
Homing projectilethe arc to the X
Item boxoutline, driven over

Mounted in the slot as an asphalt disc inside the gold frame. It reads as a rear-view mirror, which suits the panel. The weakest icon is the homing arc at HUD size; the X carries it.

Choosing. All five are inline SVG and would live in the web app as a small sprite the Instrument panel swaps on the slot's item. Trade-offs to weigh:
  1. Sixteen Bit is the only set that costs nothing in style debt; it is the panel's own language.
  2. Sticker Pack matches the kart model and the Kenney assets, at the price of a second visual language on the HUD.
  3. Pit Wall Blueprint teaches the rules, but needs the slot recoloured and its callouts dropped at HUD size.
  4. Roadside Pests gives the items personality and a reason to grin when the slot fills.
  5. Tyre Marks is the most original and the hardest to read cold; it pays off only if the track also shows these marks.

Decided: the pests, redrawn as 16x16 sprites in the panel's language (ADR 0024).
