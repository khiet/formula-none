# Assets

Blender sources and exported glTF (ADR 0007). Placeholder primitives until
milestone M1 passes its feel gate; Kenney CC0 kits afterwards. Everything in
here is CC0.

The track export carries, besides the mesh: the centreline spline,
checkpoints, item box positions, boost pad positions, the spawn grid, and
surface tags (asphalt, sand, grass, wall, out of world). The sim reads the
export, never the mesh.
