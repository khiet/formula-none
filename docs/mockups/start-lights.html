Five-light start

Issue #137: the 3-2-1 count becomes five start lights. One comes on per second, all go out at Go, then GO shows for a second. Pick a treatment, press Play, and hold the throttle (space) to try a rocket start.

What stays and what changes

  • Same spot as the old count: centred, 40% down the View. Lamps are poster-red octagons, faceted like every plate; an unlit lamp is carbon one step darker.
  • Sizes are in HUD units (--hud), so the row reads the same in an eight-window feel check as full screen. The row is about 29 HUD units wide.
  • Lights out is exactly Go, 1 s after the fifth light. No random F1 wait.
  • Rocket start edges are unchanged in seconds back from Go. Full boost: begin in the first half of light 4. Weak: second half of light 4. Clean: light 5 or later. Stall: before light 4.
  • One beep per lamp, the go sound at lights out (the game's own .wavs when served from the repo root).
