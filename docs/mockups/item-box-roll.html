Item Box Roll

Four parts to agree: how the item box turns on the road, what touching one sounds like, how the item slot rolls through the items before it settles, and how it tells you what you got. Each part has variations; pick one per part, then try them together at the bottom.

Today the box stands still, the slot fills the moment the server's pickup event lands, and the itemPickup cue (the "Coin" pick: 988 Hz then 1319 Hz) plays as it fills. The coin turns once a second and bobs 5 cm over 2 s. Sounds here are synthesised with the same kit as assets/audio/build.py, so a pick ports straight across. Click anywhere first so the browser lets sound play.

1. How the box turns

View only

The real geometry: the 1 m gold cube with an inset frame on each face, 1 m up, beside the coin for scale. Every box turns off the View's clock in unison, as the coins do, so a row of four reads as one row.

2. Touching the box

Sound at contact

Plays the instant your kart's centre is on a box, before the roll starts, so it does the coin pickup's job. It should rhyme with the coin chime but read bigger, since the box gives more.

3. The roll

Slot animation + tick

The slot cycles boost, hazard and homing, fast at first and slowing to a stop on the item the server rolled. Each change ticks. Set the length and the tick here; they apply to every reel below.

4. "You got this!"

Sound + animation on landing

Plays as the roll lands. The sound and the animation are picked separately; each animation card plays its own sound pick so you hear them together.

Rules to settle with the look

Sim, not View

A roll that lasts seconds changes the game, not only the screen, so these need an answer before it is built. Each would land in a new ADR beside ADR 0068.

  1. Is the roll a sim rule or only the View's show? a) Sim rule (Recommended): the server rolls at pickup as today, but the slot is "rolling" for the roll's length in tuning.rs; the item button does nothing until it lands, and bots wait too. Every screen agrees. b) View only: the item is usable at once and the reel is decoration a quick press skips.
  2. Does a rolling slot count as full? a) Yes (Recommended): a second box mid-roll gives nothing, as a held item does today. b) No: it queues.
  3. Can a press stop the roll early? a) No (Recommended): it always runs its length. b) Yes, after a minimum.
  4. What happens to the old itemPickup cue? a) It becomes the contact sound (Recommended), whichever you pick above, and the landing gets the new cue. b) Keep it on the slot filling and add only the landing.
